# Senparc.AI AgentKernel Console Sample 使用说明

打开解决方案并编译本控制台项目，或直接 `dotnet run`。

## 配置

1. 使用编辑工具修改 `appsettings.json`（推荐本地开发使用 `appsettings.Development.json` 覆盖敏感信息）
2. 填写 `SenparcAiSetting` 中对应平台的 ApiKey、Endpoint、模型名称
3. 如需 Embedding / RAG，请配置 `ModelName.Embedding` 与 `EmbeddingDimensions`，以及 `VectorDB`
4. 如需 MCP 示例，请配置 `SenparcAiSetting.McpServers`
5. 如需 A2A 示例，请配置 `SenparcAiSetting.A2AAgents`
6. `ToolBindingMode` 默认建议使用 `LocalFunctionProxy`（本地代理为 AIFunction，兼容当前 AgentKernel Chat 路径）
7. 若 MCP 改为 `HostedServerTool`，`LocalSseUrl` 通常需要配置 `PublicBaseUrl` 或环境变量 `MCP_PUBLIC_BASE_URL` 做公网 URL 映射（会自动保留 `/sse` 路径）
8. A2A 若使用 `LocalBaseUrl`，可配置 `PublicBaseUrl` 或环境变量 `A2A_PUBLIC_BASE_URL` 做公网 URL 映射（会自动保留路径）
9. MCP 相关标准逻辑已抽象到 `Senparc.AI.AgentKernel.Mcp`（`McpToolsetBuilder` / `McpConfigurationExtensions`），A2A 相关标准逻辑已抽象到 `Senparc.AI.AgentKernel.A2A`（`A2AToolsetBuilder` / `A2AConfigurationExtensions`）
10. Harness Agent 复用当前 Chat 模型配置；进入菜单 `[11]` 后按模型实际规格填写上下文窗口和单次输出 Token 上限

## 运行

### Windows / macOS / Linux

```bash
dotnet run --project Samples/Senparc.AI.Samples.AgentKernelConsoles
```

或在输出目录执行：

```bash
dotnet Senparc.AI.Samples.AgentKernelConsoles.dll
```

## Harness Agent

主菜单输入 `11` 启动 Harness。准确 API 为 `IChatClient.AsHarnessAgent(...)`，来自 `Microsoft.Agents.AI.Harness`。当前 Sample 使用与 AgentKernel MAF `1.8.0` 相匹配的 Harness `1.8.0-preview.260528.1`。

可用命令：`/mode`、`/mode plan`、`/mode execute`、`/todos`、`exit`。

Sample 默认关闭 Harness 的文件访问、文件记忆、Skills 扫描和 Hosted Web Search，保留上下文压缩、Todo、plan/execute 模式与人工工具审批。若需开启文件能力，应显式配置仅指向专用目录的 `FileAccessStore` / `FileMemoryStore`。

官方参考：[MAF Harness Samples](https://github.com/microsoft/agent-framework/tree/main/dotnet/samples/02-agents/Harness) · [Harness NuGet](https://www.nuget.org/packages/Microsoft.Agents.AI.Harness/1.8.0-preview.260528.1)

## 与 Consoles 示例的区别

- 本示例引用 **Senparc.AI.AgentKernel**，基于 Microsoft Agent Framework
- 对话上下文通过 **AgentSession** 维护
- 当前已覆盖 Chat / Completion / Embedding / RAG / Image / STT / TTS / MCP（LocalFunctionProxy / HostedServerTool）/ A2A（LocalFunctionProxy）/ Harness Agent
- 尚未在 AgentKernel 中实现的能力（如 Planner、Plugin）会提示「尚未提供」，可使用 `Senparc.AI.Samples.Consoles`（Kernel 版）
